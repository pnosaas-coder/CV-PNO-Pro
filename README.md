## 🌐 Déploiement GitHub Pages

Ce site peut être activé gratuitement sur **GitHub Pages** directement depuis les paramètres du dépôt :
1. Aller dans **Settings** > **Pages** sur GitHub.
2. Sélectionner la branche `main` et le dossier `/ (root)`.
3. Cliquer sur **Save**.
Le site sera alors accessible en ligne via : `https://pnosaas-coder.github.io/CV-PNO-Pro/`.
